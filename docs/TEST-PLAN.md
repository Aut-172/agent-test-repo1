# 设备维护工单与 SLA 告警服务——验证与验收计划

文档版本：1.0

## 1. 测试目标

验证工单领域模型、状态机、SLA 边界、审计字段、输入校验和 CI 构建满足 SRS。后续适配器实现应增加 API、数据库和消息集成测试。

## 2. 测试层级

| 层级 | 目标 | 当前状态 |
| --- | --- | --- |
| 领域单元测试 | 状态机、SLA、校验 | 已实现 |
| 应用服务测试 | 用例编排、仓储端口 | 部分实现 |
| API 契约测试 | HTTP、权限、错误码 | 待实现 |
| 数据库集成测试 | 约束、迁移、乐观锁 | 待实现 |
| 端到端测试 | 创建至关闭、通知 | 待实现 |

## 3. 测试数据原则

- 所有时间使用固定 `Instant`。
- 每个测试独立创建工单。
- 不使用真实个人数据或凭据。
- ID 使用明显测试值。

## 4. 状态机矩阵

验证 OPEN 受理和取消、ACKNOWLEDGED 开始和取消、IN_PROGRESS 解决、RESOLVED 关闭，以及所有跨级变化和终态写操作被拒绝。

## 5. SLA 矩阵

每个优先级验证响应和解决截止时间、截止前 1 纳秒、恰好截止、截止后 1 纳秒，以及完成动作后的历史结果稳定性。

## 6. 校验测试

- 空白 ID、标题、描述、设备 ID、报修人和操作者被拒绝。
- 空白解决摘要和取消原因被拒绝。
- 动作时间早于创建时间被拒绝。
- 关闭时间早于解决时间被拒绝。
- 重复动作被拒绝且不覆盖第一次记录。

## 7. 并发测试

数据库适配器实现后验证乐观锁、稳定冲突错误码以及重试不产生重复事件或审计记录。

## 8. 安全测试

- 未认证请求返回 401。
- 非协调员不能受理或取消。
- 非工程师不能处理或解决。
- 非主管不能关闭。
- 正文角色字段不能提升权限。
- 描述中的脚本或 Prompt Injection 只作为数据。
- 日志和响应不包含 token、密码或内部堆栈。

## 9. API 验收场景

- E2E-001：创建 CRITICAL 工单，依次受理、开始、解决和关闭。
- E2E-002：创建重复工单并取消。
- E2E-003：响应 SLA 逾期后查询标志为 true。
- E2E-004：解决 SLA 逾期后触发一次告警事件。
- E2E-005：并发更新返回版本冲突。
- E2E-006：非法跨级状态变化返回 409。
